# US Maize — In-Season Yield & Area Forecast

Weekly satellite forecast of corn yield, crop area and production for the core US Corn Belt,
published as a static site on GitHub Pages.

Live: https://rayx-eo.github.io/US_maize/

| path | what |
|---|---|
| `index.html` | viewer (MapLibre GL + PMTiles) |
| `lib/` | vendored maplibre-gl + pmtiles |
| `admin/` | Census cartographic boundaries, simplified |
| `tiles/` | crop class map and forecast yield, as PMTiles |
| `manifest.json` | weeks, headline figures, state and county statistics |
